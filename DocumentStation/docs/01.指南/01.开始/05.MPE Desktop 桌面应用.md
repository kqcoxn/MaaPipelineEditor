# Desktop 桌面应用

桌面应用提供项目管理、环境安装、版本更新和日志查看，支持 Windows x64 与 macOS Apple Silicon。Linux 请使用 Web Editor 与 mpelb。

## 开始使用

1. 从 [GitHub Releases](https://github.com/kqcoxn/MaaPipelineEditor/releases) 下载并安装对应平台的桌面应用。
2. 打开「环境管理」，按提示检查并安装环境。
3. 在「项目管理」中添加已有项目目录，选中后点击「启动编辑器」。

启动器会自动启动 LocalBridge 并连接编辑器。环境安装完成后，也可以离线使用。

项目会保留在列表中，方便下次打开。移除项目不会删除磁盘文件；目录移动后可重新定位。

若提示已有 LocalBridge 服务，可选择「中断现有服务并重新连接」。此操作会停止原服务及其运行任务。

## 环境与更新

在「环境管理」中安装、修复或切换版本，点击「更新日志」查看各版本的更新内容。Editor 与 LocalBridge 会一起更新；需要保留某个版本时，选择「固定版本」。

在设置中可分别开启：

- **自动检查 MPE 更新**：发现 Editor 与 LocalBridge 新版时提示。
- **自动安装 MPE 更新**：配合自动检查，在环境就绪且编辑会话结束后安装新版。
- **自动检查并更新 Desktop**：更新桌面启动器自身。

也可以在「环境管理」中手动检查环境更新，在设置中手动检查桌面端更新。安装更新前请先结束编辑会话。

启动器自身更新时，可在设置页与底部状态栏查看下载进度、已下载大小、总大小、平均速度和耗时。服务器未提供总大小时，进度条不显示百分比。下载完成后会校验更新包并安装，安装完成后重启；更新失败时可在设置页查看原因并重试。

桌面应用与终端共用 mpelb，切换版本也会影响终端使用的版本。若之前只安装了命令行环境，在「环境管理」中安装配套版本即可补齐编辑器。

### 下载遇到问题

Windows 支持系统手动代理。使用 Clash 等代理客户端时，请开启「系统代理」后重试；仅启动代理客户端不会接管下载。使用 PAC 自动配置时，请改用手动代理。

通常无需配置 GitHub Token。需要时可在「设置 → GitHub Token」中保存或清除；Token 不能解决网络连接问题。

无法联网时，仍可启动已安装的环境。

## 窗口与退出

默认启动编辑器后隐藏启动器，结束编辑后退出整个桌面应用。可在设置中改为编辑时保留启动器，或结束编辑后返回启动器。

编辑时关闭启动器窗口只会隐藏它；要退出整个应用，请选择「退出 MPE Desktop」。退出时，未保存的文件可选择保存、放弃或取消。

## 日志与问题反馈

调试停止超过 10 秒时，悬浮条会显示「停止尚未完成」，可点击「打开环境管理」。先保存编辑文件并导出诊断日志，再点击「结束服务」；正常停止超时后，可选择「强制结束」，随后重新打开项目。强制结束会关闭当前编辑会话及托管的运行进程。

Command 脚本的标准输入为空输入，读取时会立即得到 EOF。需要传入的数据应通过命令参数或文件提供。

在「日志」中选择来源，可查看、搜索和刷新日志；点击「打开目录」查看原始文件。

反馈问题时，点击「打包诊断日志」并选择 ZIP 保存位置。编辑器的「导出 MPE 日志」和调试面板的「一键打包诊断日志」也可使用。

诊断包包含运行日志、截图和已打开的项目文件，分享前请检查其中是否有敏感内容。编辑器卡住或关闭后，也可从启动器打包日志。

## 配置与外观

- **LocalBridge 配置**：在「环境管理」中打开 mpelb 配置文件，或使用编辑器中的可视化配置，详见 [进阶配置](/guide/server/advance)。
- **外观**：在设置中切换深浅主题、选择本地背景；关闭「氛围动画」可让背景静态显示。
