## 概述

MaaPipelineEditor 采用渐进增强的产品设计理念，提供三种使用模式：

- **纯 Web 端**：无需安装，开箱即用
- **Web + LocalBridge**：按需接入本地文件、设备和 MaaFramework 能力
- **[MSE + iframe](/guide/mse/overview)**：在 VS Code 中由 Maa Support Extension（MSE）承载 MPE，编辑当前 Pipeline 文件

| 特性       | 纯 Web 端      | Web + LocalBridge | MSE + iframe            |
| ---------- | -------------- | ----------------- | ----------------------- |
| 上手难度   | ⭐             | ⭐⭐⭐            | ⭐⭐                    |
| 功能完整度 | ⭐⭐           | ⭐⭐⭐⭐⭐        | ⭐⭐⭐⭐                |
| 使用便捷性 | ⭐⭐⭐⭐⭐     | ⭐⭐⭐            | ⭐⭐⭐⭐                |
| 配置灵活性 | ⭐             | ⭐⭐⭐⭐⭐        | ⭐⭐⭐⭐                |
| 适用场景   | 临时查看、审阅 | 日常资源开发      | VS Code 内编辑 Pipeline |
