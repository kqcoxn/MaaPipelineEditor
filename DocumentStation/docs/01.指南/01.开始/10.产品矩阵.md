## 概述

MaaPipelineEditor 采用渐进增强的产品设计理念，提供两种部署模式：

- **纯 Web 端**：无需安装，开箱即用
- **Web + LocalBridge**：按需接入本地文件、设备和 MaaFramework 能力

| 特性       | 纯 Web 端     | Web + LocalBridge |
| ---------- | ------------- | ----------------- |
| 上手难度   | ⭐            | ⭐⭐⭐              |
| 功能完整度 | ⭐⭐          | ⭐⭐⭐⭐⭐           |
| 使用便捷性 | ⭐⭐⭐⭐⭐    | ⭐⭐⭐              |
| 配置灵活性 | ⭐            | ⭐⭐⭐⭐⭐           |
| 适用场景   | 临时查看、审阅 | 日常资源开发      |

### 模式详解

#### 纯 Web 端

**适用场景**

- 快速查看和审阅他人的 Pipeline 项目
- 临时编辑或创建简单的 Pipeline 配置
- 在任意设备上进行轻量级编辑
- 无需本地环境的协作场景

**特点**

- 无需安装，打开浏览器即可使用
- 支持现代浏览器的跨平台访问
- 配置保存在浏览器本地存储中
- 可通过分享链接与他人协作

**限制**

- 无法访问本地文件系统
- 无法使用 MaaFramework 原生功能（截图、OCR、调试等）
- AI 节点补全需要 API 支持 CORS，或通过 LocalBridge 代理

#### Web + LocalBridge

**适用场景**

- 日常 Pipeline 资源开发
- 需要频繁调试和测试流程
- 多项目、多文件同时维护
- 依赖原生工具链的开发场景

**特点**

- 在 Web 端基础上按需启用本地能力
- 前后端分离，服务可独立启动
- 可自定义工作目录、MaaFramework 和 OCR 路径
- 一行命令即可启动本地服务

**核心能力**

- 递归扫描、监听、创建和保存 JSON/JSONC 文件
- 设备连接、截图、OCR 和资源管理
- 完整运行、节点级运行、追踪和识别详情查看
- 通过 LocalBridge 代理 AI 请求

**限制**

- 需要手动启动 LocalBridge 服务
- 需要通过终端查看服务日志
- 更新 LocalBridge 需手动重新安装
- 需要配置 MaaFramework 路径

## 如何选择

**初次使用或学习阶段**

- 使用纯 Web 端快速查看示例 Pipeline。

**日常资源开发**

- 推荐使用 Web + LocalBridge，功能完整且配置灵活。

**团队协作或代码审阅**

- 使用纯 Web 端，通过分享链接快速展示。

**多项目维护**

- 使用 Web + LocalBridge，按需切换本地工作目录。

## 模式迁移

从纯 Web 端迁移到 Web + LocalBridge：

1. 在 Web 端导出 Pipeline JSON 文件。
2. 启动 LocalBridge 并指定项目根目录。
3. 使用本地文件管理功能导入或打开文件。
