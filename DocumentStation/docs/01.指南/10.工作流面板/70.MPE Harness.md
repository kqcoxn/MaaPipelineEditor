## 概述

MPE Harness 是 MPE 的统一 AI 执行入口。它不再只是一次性的字段预测请求，而是围绕一个目标创建 AI Run，由 Harness 负责准备上下文、选择受控工具、执行多轮模型请求、校验编辑器状态并汇总结果。

Harness 的基本分工是：AI 负责理解目标、选择下一步工具和组织顺序；MPE 负责提供上下文、校验参数、执行画布修改、维护运行状态并判断结果是否有效。AI 不能绕过 MPE 命令层直接修改编辑器内部状态。

## 能做什么

### 画布对话

打开 MPE Harness 后，可以直接用自然语言询问当前 Pipeline，或让 Harness 在受控范围内操作当前文件的画布。例如：

- 检查当前 Pipeline 的结构和潜在问题
- 解释选中的节点或一段流程
- 创建、修改、删除节点以及调整连接
- 根据 MaaFW Pipeline 语义补全流程配置

画布对话会继承当前 Session 的有限历史。每次执行都会创建独立的 Run，并记录目标、状态、工具调用、Token 用量和最终摘要。

### AI 重排

点击 Harness 输入框上方的“AI 重排”，可以让 Harness 分析当前画布的执行语义并提交布局意图。它只调整画布的组织方式，不修改节点字段、连接或业务配置。

使用前需要保证当前文件存在可布局节点。重排结果仍然可以在画布上继续手动调整。

### 流程架构

点击“流程架构”，Harness 会读取当前 Pipeline 的真实执行结构，将节点整理为业务语义阶段视图。该功能用于理解和浏览复杂流程，不会修改节点、连接、坐标或业务配置。

## 打开 Harness

1. 点击编辑器工具栏中的 AI 对话入口。
2. 在右侧 Harness 面板中输入目标或问题。
3. 按 Enter 发送，等待 Run 完成；执行过程中可以点击停止取消当前 Run。
4. 使用 Session 切换器创建或切换对话。清空或删除 Session 会移除该 Session 在内存中的 Run 和事件记录。

Harness 的历史记录暂存在浏览器内存中，刷新页面后不会保留。

输入框以 `/` 开头时会显示命令菜单。菜单支持按命令名和说明模糊搜索，可使用方向键选择、Enter 补全、Escape 清空输入。输入 `/compact` 可以手动压缩当前 Session，也可以写成 `/compact 重点保留节点变更`，向压缩模型附加本次摘要的关注点。

## 配置 AI 服务

打开设置面板，在“AI”分类中配置以下项目：

| 配置项 | 说明 |
| --- | --- |
| API 类型 | 选择 OpenAI、Anthropic、Gemini，或选择“自定义”使用 OpenAI 兼容接口 |
| API URL | 填写服务基础地址或完整端点，Provider 会补全请求路径 |
| API Key | 服务商密钥；会使用 AES-GCM 加密保存在浏览器本地，不会随配置导出 |
| 模型 | 填写服务商对应的模型名称 |
| 温度 | 控制输出随机性，范围为 0 到 1 |
| LocalBridge 代理 | 开启后由 LocalBridge 转发请求，可绕过浏览器 CORS 限制 |
| 上下文压缩阈值 | Harness 在每次模型请求前估算请求上下文，达到此 Token 数时自动压缩较早内容；也可使用 `/compact` 手动压缩 |
| 请求超时 | 限制单次模型请求的最长时间，不限制整个 Run 的总时长 |

配置完成后点击“连接测试”确认服务可用。使用 LocalBridge 代理时，需要先启动并连接 LocalBridge；关闭代理则由浏览器直接请求 API，可能受到服务商 CORS 策略限制。

## Run、工具与安全边界

每次发送目标都会创建一个 Run。Run 会冻结以下信息，执行期间不会因为外部设置变化而改变：

- 使用的模型类型、地址、模型名称和温度
- 当前业务 Profile 及其系统规则
- 本次 Run 可用的 Skill 和工具集合
- 最大轮数、最大工具调用次数、上下文压缩阈值和重试次数

默认的“画布对话”Profile 使用当前已注册的 MPE Skill 与工具。工具调用会经过参数 Schema、权限和画布版本校验；执行结果会标记成功、失败、可重试错误或状态冲突。涉及画布的修改仍然属于可撤销的编辑操作。

工具调用预算可在设置面板的“AI”分类中调整，默认每次 Run 最多 50 次，范围为 1 到 200 次。预算在 Run 创建时固定，运行过程中修改设置不会影响已启动的 Run。需要读取多个节点时应使用 `read_nodes` 批量读取，需要修改多个节点或连接时应使用 `apply_canvas_changes` 一次提交全部变更；这样可以减少请求轮数，并保持批量修改的原子性。

上下文压缩阈值只控制上下文整理，不是 Run 的终止预算。自动压缩会请求模型总结较早的用户目标、助手回复、工具调用和工具结果，保留摘要、最近的完整用户回合以及当前画布快照，然后继续原 Run。摘要会保存在当前 Session 中，后续 Run 直接复用；工具调用次数和最大轮数仍按各自配置执行。

## 运行状态与排错

Run 状态可能为：排队中、运行中、等待工具、已完成、失败、已取消或部分完成。面板中的运行记录会显示模型回复、工具调用和执行结果。

遇到失败时，优先检查：

1. AI 配置是否完整，尤其是 API URL、API Key 和模型名称。
2. LocalBridge 是否在线；启用代理时必须能连接 LocalBridge。
3. 当前文件是否仍处于可编辑状态，是否有另一个 Run 正在执行。
4. 上下文压缩阈值、请求超时和服务商限额是否合适。
5. 工具返回的参数错误或状态冲突，并根据提示修改目标后重试。

Harness 可能在部分工具已执行后结束。请根据 Run 事件和画布实际状态确认结果，不要只依据模型最后一段文字判断修改是否完成。
