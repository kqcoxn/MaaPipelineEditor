MPE Harness 是编辑器内的 AI 助手，可以解释流程、修改节点、分析 PI 配置，以及整理画布布局。

## 配置与打开

1. 在「设置 → AI」中选择 API 类型，填写 API URL、API Key 和模型名称。
2. 点击「连接测试」，确认服务可用。
3. 点击工具栏的 AI 对话入口，或 Interface／PI 编辑器中的「AI 辅助」。
4. 输入问题或目标，按 Enter 发送。执行中可点击「停止」。

支持 OpenAI、Anthropic、Gemini 和 OpenAI 兼容接口。若浏览器请求受到跨域限制，可开启「LocalBridge 代理」，并先连接 LocalBridge。API Key 保存在浏览器本地，不随配置导出。

## 常用功能

### 项目对话

直接描述需要完成的操作，例如：

- “解释选中节点的作用，检查后续流程有没有问题。”
- “添加一个 OCR 识别节点，识别成功后点击目标。”
- “修改这几个节点的参数，并调整连接。”

Pipeline 查询可跨文件，修改仅限当前画布。画布修改可撤销，完成后请检查结果并保存。

### PI 分析与编辑

连接 LocalBridge 并选择 PI 项目后，在 Interface 或 PI 编辑器中点击「AI 辅助」。例如：

- “说明当前任务的选项，以及它们覆盖的节点。”
- “当前选项为什么没有生效？”
- “给每日任务增加一个次数输入框。”
- “重命名这个选项，并更新引用。”

默认「包含当前草稿」，可切换为「仅磁盘文件」检查已保存内容。未保存且没有文件路径的 Pipeline 不会纳入项目分析。分析配置不需要连接设备。

PI 修改会先生成差异方案，再应用到草稿并校验。可在工具记录中展开差异、查看问题，点击来源定位源码；应用后可在 PI 编辑器撤销或重做，确认后手动保存。若期间修改了项目或文件，需要重新生成方案。

### AI 重排与流程架构

- **AI 重排**：点击输入框上方的「AI 重排」，自动整理当前画布布局，不改变节点配置和连接；之后仍可手动调整。
- **流程架构**：点击「流程架构」，按业务阶段查看流程结构，方便浏览复杂 Pipeline，不修改画布。

## 对话与运行记录

使用 Session 切换器新建或切换对话。每次发送都会生成一条运行记录，可查看模型回复、工具操作和执行结果。历史记录仅保存在内存中，刷新页面后清空。

长对话会按设置自动压缩，也可输入 `/compact` 手动整理；例如 `/compact 重点保留节点变更`。

「设置 → AI」中还可调整温度、请求超时、上下文压缩阈值和工具调用预算。工具调用预算限制一次运行的操作次数，请求超时限制单次模型请求的等待时间。

## 遇到问题

- **连接失败**：检查 API 地址、密钥和模型名称；启用代理时确认 LocalBridge 已连接。
- **超时或达到调用限制**：适当调整设置，或把目标拆成几步执行。
- **状态冲突**：确认当前文件可编辑，等待其他运行结束后，重新描述目标。
- **失败或部分完成**：检查工具记录、PI 草稿和画布，确认哪些操作已经完成，再撤销或继续修改。PI 与画布修改需分别检查。
