PI 文件编辑用于编写 Project Interface 项目配置。主 `interface.json`、导入文件和语言文件可以像 Pipeline 一样分别打开为标签页；PI 标签显示表单或源码，Pipeline 标签显示画布。

## 打开文件

连接 LocalBridge 并配置项目入口后，在「本地文件」面板切换到 **Interface** 后选择文件。也可以在 Interface 首页点击「编辑项目文件」，或选中任务后点击「编辑定义」。

同一个文件再次打开时会定位已有标签；不同目录的同名文件分别展示相对路径。项目配置存在错误时，可以打开源文件修复。

## 编辑任务和选项

左侧列出本文件的任务、选项及其他定义，右侧编辑当前对象。一个文件可以包含多个任务和选项。可以新建、复制、删除和调整任务顺序，修改入口、文案、分组、默认勾选、适用资源／控制器及关联选项。

结构化表单使用加粗的字段标题。鼠标悬浮或键盘聚焦标题时，可查看字段用途、格式、默认行为、引用规则及填写示例。提示会区分任务、选项、分支、输入和快捷键等上下文，语言文件显示翻译文案的说明。字段源码弹窗的标题也支持查看提示；查看示例不会修改草稿，示例中的节点名、路径和引用标识需按实际项目填写。

选项支持分支、嵌套选项、默认值和输入校验。分支、输入字段和快捷键字段通过标题旁的拖动手柄排序。聚焦手柄后也可按空格开始排序、上下方向键移动、空格确认、Esc 取消。每次排序可通过撤销恢复。点击关联选项旁的「定义」可以打开其来源文件；需要仅改变当前任务的配置时，使用「复制后单独修改」。共享选项的修改会影响所有引用它的任务。

Pipeline 覆盖先选择目标节点，再通过「编辑字段源码」修改覆盖内容。局部源码对话框点击「应用到文件草稿」后才会生效；所有内容仍需保存文件后写入磁盘。

从画布节点的右键菜单选择「创建为 PI 任务」，可将该节点设为任务入口，并选择现有文件或新建文件保存。

## 分文件管理

- 修改已有定义时保存到它原来的文件。
- 「新建 PI 文件」默认加入当前项目，新文件与主文件的导入修改一起保存。取消加入项目时，该文件不参与运行。
- 拖动左侧对象目录中条目前的手柄，调整同类型对象的顺序；跨文件顺序在主文件的导入列表中拖动调整。搜索时暂停排序，清空搜索后恢复。
- 「移动」可以将任务或选项移入其他文件。任务的选项默认保留原位置；只有没有外部引用的专属选项可以一起移动。
- 解除导入只将文件移出项目配置，不删除磁盘文件；删除任务也不会自动删除它的选项。
- 同名选项在不同文件中定义时，界面显示生效位置。存在多个同名定义时，应先在源码中明确整理覆盖关系，再执行重命名。

## 多语言和源码

表单保留以 `$` 开头的翻译键，同时展示对应文案。点击「编辑」进入语言文件；共享文案可以复制为独立翻译键后修改。

「结构化编辑」和「源码」使用同一份文件草稿。源码暂时无效时，草稿仍保留并显示错误位置，修复后可继续使用表单。表单没有覆盖的协议字段通过源码编辑，其他字段和 JSONC 注释会保留。

## 保存与冲突

点击 PI 编辑面板中的「保存」，也可使用 `Ctrl+S`（macOS 为 `Cmd+S`）。普通保存针对当前文件；重命名引用、跨文件移动、新建并导入等关联操作会列出涉及文件并一起保存。

编辑器检查引用、默认分支、嵌套循环和配置格式。入口未出现在当前资源的磁盘索引中时显示提示；动态生成的入口需要通过运行验证。

外部修改会自动刷新没有草稿的文件。有草稿时，编辑器保留修改并提示冲突：选择「对比并合并」，查看磁盘与草稿内容，保留草稿后在源码中完成合并，再保存；也可以放弃关联草稿并重新载入。

GUI 准备、运行、调试或设备连接期间可以编辑草稿，保存需等待相关操作结束。保存成功后，Interface 自动读取已保存的项目配置。

::: tip 草稿保存范围
未保存草稿只保留在当前会话，不写入浏览器长期缓存。切换标签不会丢失修改；刷新网页、退出桌面或关闭文件前，请保存需要保留的内容。
:::
