# 可选取材方向

用于缺少主题时发散，不把下列示例当作已发生更新或必须实施的路线图。

| 取材 | 画面转译 |
| --- | --- |
| 流程编排、任务运行 | 轨道调度、港口航线、星港依次启航 |
| 调试、诊断、稳定性 | 雨夜维修铺、找出断线、共同启动一台机器 |
| 识别、截图、观察工具 | 深海观测站、光学实验室、从环境中发现目标 |
| 组织管理、易用性 | 温室引导藤蔓、整理工坊、铺设有序通路 |
| 插件、集成、开源社区 | 零件集市、各地包裹、共同建设的小城 |
| 科技发展 | 经核实的机器人协作、空间计算、芯片制造或太空探索事件，结合版本能力形成一个故事 |
| 日常与自然 | 看云海、旅途休息、雨夜灯光、季节景物，增加角色生活感 |

可选媒介包括等距微缩模型、复古科幻封面、水彩绘本、黏土定格、版画、赛璐璐动画。媒介应影响材质、光线与构图，不只是套色。

构思时可以用“角色正在做什么—与版本或热点有什么联系—哪些细节成为彩蛋”串起叙事。避免把功能名称和大量标语直接铺满背景。
