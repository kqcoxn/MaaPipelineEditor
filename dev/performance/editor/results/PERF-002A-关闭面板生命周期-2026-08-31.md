# PERF-002A 关闭面板生命周期实施记录

## 范围

本单元只处理调试抽屉关闭态的重型订阅和资源体检整图快照。没有删除调试功能、运行状态、协议监听或右键启动能力；业务架构面板属于后续 `PERF-002B`。

## 实施内容

- `DebugModal` 拆为轻量宿主和 `DebugModalContent`。关闭时不挂载 `useDebugModalController`，因此节点执行 controller、完整 FlowStore selector 和面板 UI 均卸载。
- 调试运行状态追踪保留在宿主中，后台运行结束通知不受抽屉关闭影响。
- 右键启动请求桥接增加待处理请求队列，动态内容挂载前的目标节点与运行模式不会丢失。
- 资源体检 hook 在非 `resource-health` 页不读取整图数组，也不生成 `graphSnapshot` 请求草稿；打开体检页时恢复原有完整检查。

## 验证

- `yarn --cwd Editor vitest run src/features/debug src/components/panels/main/BusinessArchitecturePanel.test.tsx`：10 个文件、54 项测试通过。
- `yarn --cwd Editor tsc --noEmit`：通过。
- `yarn lint`：通过。
- `git diff --check`：通过。

## 验收结论

关闭调试抽屉时，重型 controller 与整图资源体检草稿不再执行。调试后台状态跟踪与首次右键启动请求仍由轻量宿主和桥接队列保留。

浏览器 FPS、React commit 和 DOM 渲染指标不属于本单元的代码级验收范围，继续按 `PERF-001` 手册作为后续专项扩展测量。
