# PERF-015 首屏包与加载边界

## 结论

PERF-015A 与 PERF-015B 已完成。生产首屏不再预加载 Monaco、Tesseract、AI Markdown、业务架构或调试 UI，入口 JavaScript gzip 体积下降约 20.8%。按需功能和节点重排均提供明确的过程动画，分块加载失败可重试。

## 实施范围

- AI 历史、业务架构、调试 UI 的条件动态导入。
- `XProvider` 下沉到 AI 子树，根节点保留 Ant Design 中文 `ConfigProvider`。
- OCR、模板匹配、ROI、模板截图、取色、偏移和位移工具的功能级动态导入。
- Monaco 运行时与 loader 配置迁入动态模块。
- 移除导致共享依赖反向进入 Monaco/Tesseract 块的 `manualChunks`。
- 入口 HTML 内联不依赖主包的虚拟首屏，在 React 下载和初始化期间立即提供启动进度。
- 统一异步功能加载、失败重试和全屏过程动画。
- 无坐标导入、工具栏重排和选区右键重排统一显示“正在重排节点”。
- 布局结果以 ID Map 回写节点位置。

## 交互反馈

- 动态功能下载时显示操作标题、当前阶段、连续进度条和百分比；首次加载至少展示 2 秒，并以舒缓的遮罩、面板入场和进度过渡避免快速加载造成频闪。
- 页面入口在主脚本执行前显示轻量虚拟首屏；React 启动后原地接管同一个 HTML 节点，停止预设阶段并单调更新原进度条，加载图标和面板不会在接力处卸载重建。
- 普通启动将本地文件缓存读取、当前文件写入 FlowStore、历史基线初始化和结果绘制纳入首屏就绪条件；历史画布至少完成两次绘制机会后才开始退场，后台页面使用 100 ms 兜底。
- 虚拟首屏、React 接管和历史画布恢复共用 HTML 初始时间戳计算的 2 秒最低展示时间，不为后续阶段重复增加 2 秒。
- 生产模式保留 2 秒最低展示时间；开发模式取消功能包、过程反馈和虚拟首屏的最低时长，操作结果完成首帧绘制后立即结束反馈。
- 导入或粘贴超过 100 个节点时显示统一过程动画；100 个节点及以下保持直接执行，避免小操作产生额外视觉打断。
- 大批量粘贴一次性分配并提交全部节点顺序号，避免逐节点更新文件配置阻塞过程动画。
- 大批量粘贴使用“复制节点、刷新画布”固定阶段，只在阶段边界让出一次实际浏览器绘制帧；保留移除重复深拷贝和预先缓存 Group 边界的计算优化，不再为逐节点计数增加调度开销。
- 内部剪贴板复制超过 100 个节点时显示“复制节点、写入内部粘贴板”固定阶段；快捷键、选区菜单和全局工具栏共用同一入口，不再逐批更新节点与连接计数。
- 动态导入失败时显示重试按钮，重试会创建新的 React lazy 类型并重新调用模块加载器。
- 成功加载的 lazy 组件按加载器缓存，再次打开直接复用，不重复最低时长。
- 布局过程状态使用引用计数，可正确处理并发任务。
- 布局过程显示读取尺寸、整理图数据、计算位置、应用布局和刷新画布等实际阶段，并至少展示 2 秒；完成态在最低时长末段出现并短暂保留，避免过早停在 100%。
- 布局计算前等待两个动画帧，使遮罩先完成绘制；页面不可见导致动画帧暂停时，100 ms 后继续执行。
- 空画布和不足两个节点的局部布局不会显示无意义动画。

## 社区参考
