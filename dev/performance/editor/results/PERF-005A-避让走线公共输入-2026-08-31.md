# PERF-005A 避让走线公共输入共享

## 结论

状态：已完成。

本轮只处理避让走线的公共输入共享，不修改路径算法和路径结果语义。画布级 `AvoidanceRoutingProvider` 按布局与拓扑修订号构建节点边界列表、节点边界 Map 和平行边索引，所有 `MarkedEdge` 复用同一份输入，避免每条边重复扫描完整节点和边数组。

## 实现范围

- `Editor/src/components/flow/avoidanceRoutingContext.tsx`：新增画布级上下文，仅在 `edgePathMode === "avoid"` 时订阅图数据，并提供稳定的边界列表/Map。
- `Editor/src/core/avoidanceUtils.ts`：为边界构建增加 ID Map 查找；新增 Group 排除和按边数组顺序生成平行边索引的公共函数。
- `Editor/src/components/flow/edges.tsx`：避让边只消费上下文中的 `nodeBoundsList` 与自身的平行边信息，不再订阅完整 `nodes`、`edges`。
- `Editor/src/components/Flow.tsx`：在主画布包裹避让路由上下文，保持 FlowStore、导出、选择和 React Flow 完整图数据不变。
- `Editor/src/core/avoidanceRouting.test.ts` 与 `Editor/src/core/parser/performanceDataset.test.ts`：覆盖公共输入语义和大图构建次数。

## 固定输入与专项结果

数据集：`dev/performance/editor/datasets/performance-large-300.json`，300 个节点、900 条边，其中 291 个非 Group 节点参与避让边界。

命令：

```bash
yarn --cwd Editor vitest run src/core/parser/performanceDataset.test.ts -t "PERF-005A" --reporter=verbose
```

专项输出：

```text
[PERF-005A] large shared inputs: bounds-builds=900->1, parallel-groups=900->1, bounds=291, edges=900
```

这里的 `900 -> 1` 是同一批边在一帧内构建公共输入的次数，不是浏览器帧率或路径算法耗时。路径仍由每条边独立执行 `calculateAvoidancePath`，以保证本轮只改变公共输入来源。
