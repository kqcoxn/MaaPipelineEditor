# PERF-004 图索引、修订号与窄 selector

## 结论

状态：已完成

FlowStore 现已集中维护节点、边、邻接关系、节点语义、Anchor 引用、同名副本和选择关系索引，并使用布局、拓扑、语义、选择四类独立修订号。节点位置更新只影响布局消费者；拖动中的位置事件暂不复制完整 `nodeById`，松手后再同步受影响节点，因此不会重建语义或邻接索引，也不会通知只关心语义和拓扑的订阅者。

本项的核心收益是消除每个画布节点在每次 Store 更新时扫描完整节点或边数组的扩散成本。初版实现中的不可变 `nodeById` Map 分支复制使纯 Store 更新耗时有所增加；拖动期延迟完整索引同步后，单次更新 P95 降至约 `0.034 ms`，仍低于 `0.1 ms`。组件级结构化访问量从近似平方级降为按实际邻接边或单次索引查询增长。

## 实现范围

- 新增 `nodeById`、`nodeSemanticById`、`edgeById`、出入边 ID、节点类型与标签、Anchor 引用索引。
- 新增 `layoutRevision`、`topologyRevision`、`semanticRevision`、`selectionRevision`，并由各写入口按变化类别更新。
- 新增共享选择 ID、选中边端点和 Sticker 状态索引，节点和边聚焦透明度不再扫描完整选择与边数组。
- Pipeline 的 `next`、`on_error` 标签按当前节点出边查询并继续按 `edge.label` 排序。
- Anchor 引用、Anchor/External 同名副本数和父链坐标查询改为索引访问。
- 调试资源快照和业务架构陈旧状态只受语义、拓扑变化驱动，忽略纯布局变化。
- 导入、替换和粘贴使用确定性的全量索引重建；拖动、字段修改、普通增删、边重连、分组使用增量补丁。
- `addNode({ link: true })` 的新节点与自动连边在同一次 Store 更新中提交。

## 热路径结果

优化前的同命令独立观测为：

| 进程 | 三轮 300 次更新 | 单次更新 P95 |
| --- | --- | ---: |
| 优化前 | `5.68 / 4.33 / 9.37 ms` | `0.025 ms` |

初版优化实现的三次独立观测为：

| 进程 | 三轮 300 次更新 | 单次更新 P95 | 松手同步调度 | 松手状态稳定 |
| ---: | --- | ---: | ---: | ---: |
| 1 | `17.39 / 13.78 / 18.26 ms` | `0.075 ms` | `0.434 ms` | `3.554 ms` |
| 2 | `15.46 / 8.53 / 9.77 ms` | `0.045 ms` | `0.307 ms` | `3.041 ms` |
| 3 | `11.42 / 12.88 / 9.44 ms` | `0.051 ms` | `0.306 ms` | `3.235 ms` |

九轮总耗时中位数为 `12.88 ms`，即每次位置更新约 `0.043 ms`。这部分增加来自维护不可变 `nodeById` Map；测试不包含 React 订阅传播和组件 selector，因此不能用它单独衡量本项的主要收益。

拖动写入侧缓解后的三次独立观测为：

| 进程 | 三轮 300 次更新 | 单次更新 P95 |
| ---: | --- | ---: |
| 1 | `7.66 / 6.57 / 4.97 ms` | `0.035 ms` |
| 2 | `8.12 / 5.70 / 5.37 ms` | `0.034 ms` |
| 3 | `7.01 / 5.68 / 8.35 ms` | `0.029 ms` |

缓解后三次进程的三轮总耗时外层中位数为 `19.20 ms`，相对初版 `27.86 ms` 降低约 `31.1%`，但仍比 PERF-004 前的同机基线 `15.40 ms` 高约 `24.7%`。这是 Store-only 指标的残余固定成本，不应抵消 selector 扩散从 `270000 / 270000 / 9000` 降至 `900 / 1800 / 30` 的收益判断。

## Selector 扩散结果

large 数据集对全部画布节点执行一次派生查询时，结构化访问量如下：

| 查询 | 优化前 | 优化后 | 减少 | 倍数 |
| --- | ---: | ---: | ---: | ---: |
| Pipeline 流程标签 | 270000 | 900 | 99.67% | 300 倍 |
| 节点聚焦关系 | 270000 | 1800 | 99.33% | 150 倍 |
| Anchor/External 同名副本 | 9000 | 30 | 99.67% | 300 倍 |

连续 100 次位置更新期间，`semanticRevision` 与 `topologyRevision` 均保持不变，对应订阅通知次数均为 0；`nodeSemanticById` 与出边邻接 Map 引用保持稳定。
