# PERF-005B 避让结果缓存与精确失效

## 实施信息

- 实施日期：2026-08-31
- 适用范围：`Editor`
- 关联计划：`dev/plans/编辑器性能优化计划.md` 的 `PERF-005B`
- 测试数据集：`performance-large-300.json`，300 个节点、900 条边
- Worker：未引入，继续在主线程执行纯路径算法

## 实现摘要

- 路径结果携带折点和实际阻挡节点 ID，用于建立缓存条目的空间范围与依赖集合。
- 缓存键包含边 ID、源/目标节点与坐标、Handle 方向、平行边索引/总数和避让配置。
- 每个画布的 `AvoidanceRoutingProvider` 持有一份 `AvoidanceRouteCache`，边组件只通过 `getAvoidancePath` 读取结果。
- 历史阻挡节点边界变化会失效；新节点或移动节点的新旧边界与旧路径包围盒相交时失效；拓扑删除按边 ID 裁剪，端点、平行边和配置变化由缓存键失效。
- Provider 在布局修订提交后主动清理受影响条目，避免未挂载边错过某次节点移动；当前修订内新生成的结果不会被该清理重复删除。
