# Interface GUI 工作区实现与验收

## 定位与边界

Interface 是独立的项目运行界面，画布／调试器负责开发与诊断。GUI 运行不提交调试请求，不构建调试快照，不应用调试覆盖，不要求入口能定位到画布。可选的「在画布中查看」仅用于导航。

布局参考 MFAAvalonia 的任务／设置分区及 MXU 的嵌套选项；沿用 Ant Design 主题。界面包括任务勾选与排序、预设应用、选项配置、设备画面、日志、进度和停止操作。

## 实现结构

- `interfacerun` 服务拥有独立 Tasker、Resource、Agent 生命周期及顺序执行队列；`/etl/interface-run/*` 提供准备、开始、停止和状态查询。
- LB 接受请求时校验项目版本、任务存在性、适用条件、设备类型和所有选项，冻结本次配置。运行直接使用磁盘资源，不混入画布未保存内容。
- `mfw.AcquireExecution` 协调 GUI／调试器互斥及控制器租约；连接设备、销毁活动设备、重载框架不能破坏执行中资源。
- `pretask` 在连接设备前依次执行。准备凭证绑定项目版本、控制器、资源和预任务选项；设备必须在准备结束后创建。程序输出进入日志，命令参数不输出。
- GUI 使用自己的 Agent 事件总线，不向调试上下文发布运行日志。结束后先销毁 Tasker，再释放 Agent，最后销毁 Resource。
- 前端 `interfaceRunStore` 独立订阅运行协议，拒绝乱序结果、阻止重复启动，并在重新连接时查询服务状态。切换页面、浏览任务和修改选项不会停止运行。
- `ProjectTaskList` 管理浏览、勾选、顺序、预设；`InterfaceViewport` 复用后台截图协议并控制串行刷新；`InterfaceMonitor` 展示和导出日志。
- 缓存按 LB 地址和项目隔离；任务勾选、顺序与普通选项进入 localStorage。密码、运行记录及准备凭证不持久化。

## 已知边界

- 日志保存最近 500 条，单条最多 8000 字节，仅在 LB 内存保留，重启后清空。
- 输入验证错误会阻止整组任务启动；任务执行失败后停止队列，不自动跳过或重试。
- `focus` 内容进入日志，尚无完整 GUI 的弹窗、阻塞交互、模板上下文替换及远程说明加载。
- 非空密码仍受底层日志保护限制而不能执行。
- 预设可应用，不编辑或写回发布预设；运行环境必须由用户明确连接设备。

## 验证与手测

自动验证覆盖：任务顺序、失败与取消后不执行后续项、动态入口无需索引、过期和不兼容任务、覆盖隔离、日志边界、预任务参数与工作目录、执行互斥、队列缓存、请求关联及断线恢复。使用 Go 测试、Vitest、ESLint、antd lint 和 Editor 构建，不启动开发服务器或浏览器测试。

手测使用 `/Users/kqcoxn/_Programs/MaaDuDuL-backup/interface.json`：

1. 确认 Interface 显示任务、配置、画面与日志；缩窄窗口后仍能访问全部内容。
2. 勾选两个低风险任务，调整顺序、应用预设、刷新后核对缓存；点击名称只浏览，不改变勾选。
3. 连接匹配设备开始运行，确认没有打开调试器或切换画布，按顺序执行且各任务选项独立。
4. 暂停画面刷新、放大画面、关闭日志跟随、导出日志；停止后保留结果。
5. 运行中切换任务、修改选项、进入画布；本次任务与配置保持不变。断开网页连接后重新连接，恢复运行状态，不重复启动。
6. GUI 运行时尝试调试，调试时尝试 GUI 运行，以及运行时断开设备／重载服务，均应得到占用提示。
7. 有预任务的项目先断开设备，准备项目后重新连接；修改预任务选项或 PI 后旧凭证不能启动；准备过程可停止。
8. 缺少设备、类型不匹配、无效选项、资源加载失败和任务失败均有可读错误，不能自动续跑。
9. 回归手动调试、PI 仅环境配置调试与嵌入模式。
