# PI 第二阶段：分文件编辑与验收

## 使用方式

PI 主文件、导入文件和语言文件共用现有文件面板和标签栏；Pipeline 使用画布，PI 使用结构化表单或源码编辑器。Interface 首页仍负责运行，通过「编辑项目文件」「编辑定义」进入源文件。

编辑始终以原始文件为准，项目合并结果仅用于引用、校验与生效位置提示。草稿仅保留在当前会话；切换标签不丢修改，刷新或退出前应保存。关联修改会列出涉及的文件并一起保存。

## 实现组成

- `pi-editor` 提供独立文档草稿、每文件选择与撤销、关联修改、原文局部修改、结构化表单、源码、引用跳转和冲突对比。
- LocalBridge 的 PI 编辑接口提供读取、草稿校验和保存；读取与校验返回原始文件、版本、定义、引用和诊断，不使用翻译后的运行快照写回文件。
- 保存检查涉及文件和项目来源版本，预先验证整组内容。普通编辑不引入新的错误；已有无关错误允许逐步修复。语法无效的文件不能保存。
- 写入通过原目录临时文件替换，事务恢复记录位于项目入口目录的 `.mpe-pi-transaction.json`。成功后删除记录；失败回滚；启动或刷新时先恢复未完成保存。恢复遇到新的外部修改时保持记录并阻止运行，避免覆盖外部内容。
- PI 保存与 GUI 准备、运行、调试及设备连接共用互斥机制；编辑草稿不占用执行环境。
- 文件监听覆盖 PI 来源与编辑中打开的文件，自动发现和显式指定的项目均可接收外部变更。

## 可编辑内容

主文件支持项目文案、控制器、资源、分组、导入顺序、全局选项、语言文件声明和 Agent 配置。任务支持新建、复制、删除、排序、移动、重命名、入口及选项关联。 导入列表、对象目录及分支／输入／快捷键字段通过拖动手柄排序，支持键盘移动与取消；排序保留当前对象选择，并可撤销或重做。选项支持选择、开关、多选、输入和快捷键字段，包含分支、默认值、嵌套关联、输入校验与覆盖内容。

覆盖内容以目标节点选择和局部源码方式编辑。其他协议字段保留，可通过文件或对象源码修改。发布预设没有专用表单，其源码与任务／选项引用参与检查。

跨文件移动任务默认保留选项定义；选择一起移动时只允许没有外部引用的专属选项。删除任务保留关联选项。解除导入保留磁盘文件。同名选项展示生效与被覆盖定义；存在多个同名定义时，重命名需先通过源码明确处理覆盖关系，避免错误修改引用。

## 验证

自动测试覆盖原始内容、JSONC 注释、换行和未知字段保留，数字与转义键路径，任务排序，分文件导航、草稿和撤销，共享选项的引用重命名与移动限制，语法错误修复、外部修改、版本冲突、新文件与导入关联保存、失败回滚、中断恢复、恢复时外部编辑保护和执行互斥。

MaaDuDuL-backup 验证使用其主文件、导入文件和语言文件的临时副本，不修改参考项目，不执行 Agent 或实际设备任务。CI 无参考副本时跳过该用例；可通过 `MPE_PI_REFERENCE_ROOT` 指定参考项目目录。

手动验收：

1. 重启 LocalBridge、刷新网页，在文件面板打开主文件、`tasks/daily/purchase.json` 和语言文件，确认同名不同路径的文件标签独立。
2. 在「每日采购」中修改文案引用、展开分支、跳转子选项；在其他标签往返后，核对草稿、选中对象与撤销。
3. 切换源码，输入暂时无效的 JSONC，确认草稿保留且错误可定位；修复后回到表单。
4. 从画布节点创建 PI 任务，选择新建文件并加入项目；保存前核对主文件与新文件一起提交，保存后回到 Interface 查看任务。
5. 复制共享选项后单独修改、重命名选项，核对所有明确引用；移动任务时确认共享选项留在原位置。
6. 调整导入顺序，核对任务顺序和同名选项生效位置；解除导入后确认磁盘文件仍保留。
7. 使用外部编辑器修改已打开的文件：干净标签自动刷新，有草稿时显示冲突；对比、手动合并后保存，确认外部内容不被无提示覆盖。
8. GUI 准备／运行或调试时保存应被阻止；停止后可以保存。关闭含未保存修改的标签可保存、放弃或取消；桌面退出会提示未保存 PI 草稿。
9. 回归 Pipeline 打开、保存、画布切换、Interface 运行与嵌入模式。全程不自动启动开发服务器或浏览器测试。
